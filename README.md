# 🎮 NEXUS ARCADE — Школьный Игровой Портал

Современная, стильная веб-платформа с ультра-геймерским неоновым дизайном, тремя переключаемыми темами, полноценной системой профилей и аккаунтов, встроенными играми и режимом маскировки для школы.

---

## 🌟 Главные Особенности

### 1. 🎨 3 Цветовые Темы Оформления:
- 🔵 **Синяя тема (По умолчанию / Default)**: *Cyber Electric Blue* — глубокий темно-синий/индиго фон с неоновым бирюзовым и синим свечением.
- ⚫ **Чёрная тема**: *OLED Midnight Dark* — глубокий обсидиановый контрастный темный стиль с неоновыми фиолетовыми акцентами.
- ⚪ **Белая тема**: *Polar Clean Light* — ультра-чистый, контрастный и элегантный светлый интерфейс.

### 2. 👤 Продвинутая Система Аккаунтов & XP:
- Регистрация и Вход с выбором крутых аватаров (Кибер-ниндзя, Роботы, Пиксельные маги и др.).
- Прокачка **Уровня (Level) и XP** за матчи, победы и новые рекорды.
- Праздничные конфетти и анимации при повышении уровня.
- **Экспорт и Импорт сохранений (.JSON)** — возможность сохранить свой прогресс и перенести аккаунт на любой другой школьный или домашний компьютер!
- Список избранных игр и персональные рекорды.

### 3. 🕹️ Стартовая Коллекция Встроенных Игр:
1. **Cyber Runner 2077**: Неоновый платформер-раннер с двойными прыжками, подкатами, сбором кристаллов и лазерами.
2. **Space Nebula Strike**: Космический шутер с волнами пришельцев, апгрейдом тройных лазеров, щитами и боссами.
3. **Neon Snake X**: Светящаяся неоновая змейка со спецэффектами, частицами и ускорением.
4. **Cyber 2048 Neon**: Логическая головоломка 2048 с неоновыми плитками и возможностью отмены хода.
5. **Flappy Cyber Drone**: Физический аркадный таймкиллер с неоновыми воротами и комбо.
6. **Neon Tower Stack**: 3D-изометрическая игра на реакцию по строительству кибер-башни.

### 4. ➕ Простое Добавление Новых Игр:
- Кнопка **"+ Добавить Игру"** прямо в шапке сайта позволяет вставить любую веб-игру, HTML5 или iframe ссылку.
- Или добавьте игру в файл конфигурации `src/data/gamesConfig.ts`.

### 5. 🕵️ Режим Маскировки (School Stealth Mode / Panic Button):
- Нажатие кнопки **«Маскировка»** в шапке или клавиши **`ESC`** мгновенно подменяет игровой экран на аккуратный электронный конспект уроков и калькулятор по информатике/физике.
- Нажмите кнопку возврата или `ESC` снова, чтобы мгновенно вернуться к игре!

### 6. 🔊 Звуковой Движок:
- Встроенные процедурные ретро-аркадные звуки кликов, прыжков, монет, взрывов и побед (Web Audio API без задержек).
- Быстрое отключение/включение звука одной кнопкой в шапке сайта.

## 🚀 Запуск Проекта

### Режим разработки:
```bash
npm run dev
```
После запуска откройте в браузере адрес: `http://localhost:3000` (или указанный в консоли).

### Сборка для публикации:
```bash
npm run build
```
Готовые файлы для хостинга (GitHub Pages, Vercel, Netlify, флешка) появятся в папке `dist/`.

---

## ⌨️ Управление и Горячие Клавиши:
- **`ESC`** — Включить / Выключить школьную маскировку (Stealth Mode).
- **`Пробел` / `WASD` / `Стрелки`** — Управление в играх.
- **`P`** — Пауза в играх.
